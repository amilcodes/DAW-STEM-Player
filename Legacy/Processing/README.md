# Original Processing prototype

These files are the first version of the project. They depend on Processing and Minim and are not part of the current macOS build.

The prototype proved the basic idea: load several files, keep them aligned, and expose one volume control per stem. The current application replaces it with SwiftUI, AVAudioEngine, native trackpad input, project packages, offline export, and local stem separation.

The files remain here as historical reference only.
